# 评价种子内容 (Seed Reviews)

这个目录用来给 app **冷启动**铺真实的课程/老师评价——让新用户第一天进来就看到一个"有人用"的社区，而不是空房间。

## ⚠️ 唯一铁律：只填**真实**评价

- ✅ 你、同学、学长学姐**真上过**的课/老师，凭真实体验写。
- ❌ 不许用 AI 编、不许凭空捏造、不许刷好评。

> 为什么：假评价会被 App Store 审核拒/下架，学生一眼能看穿，信任崩了就回不来。**真实口碑是这个产品唯一的护城河**，造假等于自拆地基。

**最快铺满的办法**：拉 8-10 个同学，每人填 10 条自己真上过的课 → 100+ 条真实评价，一下午搞定。

## 怎么填

1. 用 **Google Sheets / Excel** 打开对应的 `.csv`（用表格软件填，逗号和换行会自动处理好）。
2. 一行一条评价，按列填。填完 **导出为 CSV**，覆盖回这个文件。
3. 模板里的示例行请**删掉或替换**成真实内容。

### `course_reviews.csv` 列说明

| 列 | 必填 | 说明 |
|---|---|---|
| `course_code` | ✅ | 课程代码，如 `COMP3015`（不区分大小写/空格） |
| `course_name` | 选填 | 课程名。**仅当该课还不在库里时**用来创建，已有课可留空 |
| `rating` | ✅ | 综合评分 1-5（整数） |
| `difficulty` | ✅ | 难度 1-5（1=很简单，5=很难） |
| `workload` | 选填 | 作业量 1-5（1=很少，5=很多） |
| `grading` | 选填 | 给分 1-5（1=给分严，5=给分大方） |
| `tags` | 选填 | 标签，**分号 `;` 分隔**。建议用：`Chill课;给分高;点名严;作业多;要小组;干货多;水课;考试难;实用;讲解清晰` |
| `semester` | 选填 | 学期，如 `2024 Fall` |
| `content` | ✅ | 评价正文（真实感受，最好 ≥15 字） |

### `teacher_reviews.csv` 列说明

| 列 | 必填 | 说明 |
|---|---|---|
| `teacher_name` | ✅ | 老师姓名，需与库里教师名册匹配（不区分大小写）。**匹配不上会跳过并提示** |
| `rating` | ✅ | 综合评分 1-5 |
| `difficulty` | ✅ | 难度 1-5 |
| `clarity` | 选填 | 讲课清晰度 1-5 |
| `workload` | 选填 | 作业量 1-5 |
| `tags` | 选填 | 分号分隔。建议：`讲课清晰;给分大方;有耐心;作业多;考试难;互动好;有趣;严格;宝藏老师;照本宣科` |
| `content` | ✅ | 评价正文 |

## 怎么导入

需要 Supabase 的 **service role key**（在 Supabase 控制台 → Project Settings → API → `service_role`，**保密，别提交进 git**）：

```bash
SUPABASE_SERVICE_ROLE_KEY=your_service_role_key npx tsx scripts/seed_reviews.ts
```

脚本会：解析 CSV → 校验每行 → 解析课程代码/老师名 → 写入（匿名归属、时间分散到过去 8 周）→ 自动重算每门课/每位老师的平均分与评价数 → 打印导入/跳过统计。

可先**预演不写库**：

```bash
SUPABASE_SERVICE_ROLE_KEY=xxx npx tsx scripts/seed_reviews.ts --dry-run
```
